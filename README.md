# 🎵 Quiz Musical

## 📌 Sobre o Projeto

O **Quiz Musical** é um site desenvolvido no formato de quiz interativo, com o objetivo de testar e ampliar os conhecimentos dos usuários sobre o universo da música.

As perguntas são armazenadas em um banco de dados SQL e apresentadas aos usuários durante o quiz, permitindo uma experiência dinâmica e organizada.

O projeto aborda dois temas principais:

- 🎸 **Instrumentos Musicais:** perguntas sobre diferentes instrumentos, suas características e funcionalidades.
- 🎧 **Gêneros Musicais:** perguntas sobre estilos musicais, suas características e particularidades.

## 🚀 Tecnologias Utilizadas

O desenvolvimento do projeto utiliza as seguintes tecnologias:

- **PHP** – Processamento e funcionalidades do sistema.
- **SQL** – Armazenamento e gerenciamento das perguntas no banco de dados.
- **HTML** – Estruturação das páginas.
- **CSS** – Estilização e identidade visual do site.
